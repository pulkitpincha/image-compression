# image-compression

Using K-Means to compress images

## Analysis

- We can see that all clusters look homogenous and they are of 1 color per cluster.
- K-Means isn't an appropriate technique for object identification because it primarily serves as a numerical clustering tool. It lacks the capability to effectively distinguish between objects in an image. K-means groups together data points based on their similarity, without necessarily considering whether they belong to the same object or not.
- And we can see that the three objects cannot be detected visually.
